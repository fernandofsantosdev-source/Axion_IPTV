# Worker legado descontinuado

Não publique nem configure o Worker antigo desta pasta. Ele aceitava fluxos de mídia e tickets e não corresponde mais ao modelo seguro atual do AXION.

O Worker ativo é o de [`../worker/`](../worker/), restrito a playlists e com instruções em português em [`../worker/README.md`](../worker/README.md). O AXION nunca encaminha vídeo pelo Worker; AVPlay e `<video>` usam a URL original.

As instruções antigas de publicação foram removidas para evitar que um proxy de mídia incompatível seja ativado por engano. Nenhum Worker foi publicado nesta mudança.
